 Basic CRUD API with Node.js, PostgreSQL & Docker

This is a simple CRUD API project built using Node.js with MVC architecture. It uses PostgreSQL as the database, running inside a Docker container. Input validation is handled using Joi, and Postman is used for testing the API endpoints.

## Features

- Node.js backend with MVC structure
- PostgreSQL database (via Docker)
- Input validation using Joi
- RESTful CRUD operations
- Tested with Postman

## Tech Stack

- **Backend**: Node.js, Express
- **Database**: PostgreSQL (Dockerized)
- **Validation**: Joi
- **Testing**: Postman
- **Containerization**: Docker
